Notes for implementation & layout

  1. Entry points & roles — keep a single entry (Auth) and route users to role-specific dashboards in Next.js using middleware for server-side role checks.
  2. Realtime & triggers — use Supabase Realtime or Firestore triggers to push notifications and update analytics pipelines.
  3. Storage — store images, PDFs, and assignment files in Cloudinary (free tier) or Supabase Storage.
  4. Notifications — use Firebase Cloud Messaging for push; SMTP / transactional email provider for emails; use cheap SMS only when necessary.
  5. Offline / Mobile — Next.js + PWA approach for offline-read on student dashboards for schedules and assignments.
  6. Zero-cost hosting — Vercel free tier for Next.js, Supabase free tier for backend; Cloudinary free-tier for media.
